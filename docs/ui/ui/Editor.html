Design a Rate Limiter

Design a service that limits how many requests each client can make to a public API, across a fleet of API servers.

Functional requirements

  • Limit requests per user and per API key
  • Support different limits per endpoint
  • Tell clients when they are throttled

Non-functional requirements

  • Adds very little latency to each request
  • Highly available; no single point of failure

Scale hints

10M daily active users 5k requests/sec at peak
